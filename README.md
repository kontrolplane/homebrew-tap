# kontrolplane homebrew tap

Homebrew casks for [kontrolplane](https://kontrolplane.dev) tools.

## Install

```sh
brew install kontrolplane/tap/kue
brew install kontrolplane/tap/tsui
```

Or tap once and install by name:

```sh
brew tap kontrolplane/tap
brew install tsui
```

## Casks

| Name | Description |
| ---- | ----------- |
| [kue](https://github.com/kontrolplane/kue) | A terminal user interface for Amazon SQS. |
| [tsui](https://github.com/kontrolplane/tsui) | A terminal user interface for NATS. |

## Maintenance

Casks in `Casks/` are generated by GoReleaser on every tagged release of the source
repository. Don't edit them by hand; the next release will overwrite them.
